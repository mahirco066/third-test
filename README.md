# تطبيق عيادة الدكتورة نوال مكبي (نساء وتوليد) 🩺👶

تطبيق ويب تقدمي (PWA / Hybrid Mobile App) متكامل لعيادة أمراض النساء والتوليد باسم **الدكتورة نوال مكبي**.

---

## 📱 الميزات المنفذة في التصميم:
1. **الشاشة الرئيسية (Home):**
   - هوية العيادة والتعريف بالطبيبة واستشارية التخصص.
   - زر سريع لحجز موعد فوري.
   - قائمة بأهم الخدمات الطبية التخصصية.
   - ساعات ومواعيد العمل وأرقام الاتصال.
2. **نظام حجز المواعيد (Appointment Booking):**
   - اختيار نوع الكشف والخدمة.
   - تحديد تاريخ الموعد والفترة المسائية المفضلة.
   - إمكانية الحجز المباشر عبر **WhatsApp**.
3. **أداة حاسبة الحمل وموعد الولادة المتوقع (Pregnancy Due Date Calculator):**
   - تعتمد على القواعد الطبية (قاعدة ناغلي - Naegele's rule).
   - توضيح أسبوع الحمل الحالي والثلث (Trimester) وموعد الولادة المقدر.
4. **شاشة الخدمات الطبية التخصصية:**
   - متابعة الحمل الحرج، السونار الرباعي، الولادة بدون ألم، وجراحة المناظير.

---

## 🚀 كيفية تجربة التطبيق وتشغيله محلياً:
- افتح ملف [index.html](index.html) مباشرة في أي متصفح ويب على جهازك أو هاتفك.
- يمكنك تفعيل وضع الهاتف في المتصفح عبر الضغط على `F12` ثم أيقونة الموبايل (`Ctrl + Shift + M`).

---

## 📦 كيفية تحويله إلى تطبيق أندرويد و iOS حقيقي (APK / IPA):

يمكنك تحويل هذا التصميم إلى تطبيق موبايل أصلي باستخدام أداة **Capacitor** بخطوات بسيطة:

```bash
# 1. تهيئة مشروع npm
npm init -y

# 2. تثبيت Capacitor
npm install @capacitor/core @capacitor/cli @capacitor/android

# 3. تهيئة التطبيق
npx cap init "DrNawalClinic" "com.drnawal.clinic" --web-dir .

# 4. إضافة منصة الأندرويد
npx cap add android

# 5. فتح المشروع في Android Studio لتوليد الـ APK
npx cap open android
```
