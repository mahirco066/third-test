# تطبيق عيادة الدكتورة نوال مكبي (نساء وتوليد) 🩺👶🤰

تطبيق متكامل لعيادة أمراض النساء والتوليد باسم **الدكتورة نوال مكبي**، مصمم كـ Progressive Web App (PWA) / تطبيق موبايل هجين تفاعلي بالكامل باللغة العربية مع دعم الاتجاه RTL.

---

## 📱 ميزات وشاشات التطبيق:

1. **شاشة الدخول الترحيبية (Splash / Welcome Screen):**
   - تصميم جمالي بصورة أم حامل عالية الدقة ووسم "رعاية أمومة متكاملة".
   - شعار وهوية العيادة والتعريف بالدكتورة نوال مكبي.
   - زر تفاعلي عصري: **"دخول إلى العيادة"** مع انتقال سلس.

2. **الشاشة الرئيسية (Home):**
   - بنر ترحيبي وتوعوي لصحة الأم والجنين.
   - زر الحجز السريع المباشر.
   - عرض أهم الخدمات التخصصية ومواعيد العمل وأرقام الاتصال.

3. **نظام حجز المواعيد والإشعار التلقائي بالواتساب:**
   - نموذج إدخال بيانات المريضة ونوع الكشف واليوم والفترة الزمنية والملاحظات.
   - عند تأكيد الحجز، يتم فتح **WhatsApp** تلقائياً لإرسال إشعار تفصيلي وفوري لرقم العيادة.

4. **بوابة الطبيبة لتأكيد المواعيد (Doctor Dashboard):**
   - زر مخصص في الشريط العلوي للدكتورة / السكرتارية.
   - استعراض طلبات الحجز قيد الانتظار وتفاصيل كل مريضة.
   - **تأكيد الحجز بنقرة واحدة:** إرسال رسالة واتساب رسمية ومجهزة مسبقاً من الدكتورة نوال مكبي إلى هاتف المريضة مباشرة لتأكيد موعدها وتفاصيل الحضور.

5. **أداة حاسبة الحمل وتاريخ الولادة المتوقع:**
   - مبنية على القواعد الطبية الدقيقة (قاعدة ناغلي).
   - حساب تاريخ الولادة المتوقع، أسبوع الحمل الحالي، والثلث (Trimester).

6. **شاشة الخدمات الطبية التخصصية:**
   - متابعة الحمل عالي الخطورة، الولادة بدون ألم، السونار رباعي الأبعاد (4D)، وجراحة المناظير.

---

## 🚀 كيفية تجربة التطبيق محلياً:
- افتح ملف `index.html` في أي متصفح ويب على هاتفك أو حاسوبك.
- لتجربة وضع الهاتف على الحاسوب: اضغط `F12` ثم فعّل خيار عرض الموبايل (`Ctrl + Shift + M`).

---

## 🌐 أوامر التحديث والرفع إلى مستودع GitHub:

إذا كان المستودع موجوداً مسبقاً على جهازك:
```bash
git add .
git commit -m "Update: Added welcome splash screen with pregnant woman image, doctor confirmation dashboard, and WhatsApp notifications"
git push origin main
```

إذا كنت ترفع المشروع لأول مرة إلى مستودع جديد على GitHub:
```bash
# 1. تهيئة المستودع
git init

# 2. إضافة كافة الملفات
git add .

# 3. حفظ التعديلات
git commit -m "Initial commit - Dr Nawal Clinic App with Welcome Screen & Doctor Dashboard"

# 4. تحديد الفرع الرئيسي
git branch -M main

# 5. ربط المستودع بموقع GitHub (استبدل الرابط برابط مستودعك الخاص)
git remote add origin https://github.com/USERNAME/dr-nawal-clinic-app.git

# 6. رفع الكود
git push -u origin main
```

## 📦 تحويل المشروع لتطبيق Android APK عبر Capacitor:
```bash
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "DrNawalClinic" "com.drnawal.clinic" --web-dir .
npx cap add android
npx cap open android
```
